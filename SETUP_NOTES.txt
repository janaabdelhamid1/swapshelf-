SwapShelf simplified project
============================
Changes:
- Add Book saves isSwapped=false, swappedAt=null, swapRequestId=null.
- Send Request selects exactly ONE offered book and stores selectedOfferedBookId.
- My Shelf retains My Books, Incoming and Sent; Reschedule action removed from UI.
- Both parties must confirm an accepted swap. Completion marks both books isSwapped=true.
- Home hides swapped books; My Shelf keeps them labeled Swapped.
- Existing designs, login, profile and location screens preserved.

To run on your own Windows computer:
1. Open the swapshelf_app folder in VS Code.
2. Run flutter pub get
3. Run flutter analyze
4. Run flutter run
5. Check Firestore rules allow only appropriate users to write requests/books.
   For production, validate completion atomically on trusted backend.
This environment does not have Flutter/Dart installed, so compilation and Firebase
runtime behavior could not be verified here.
Original zip included generated build/cache files; these were excluded from the
returned zip to make it smaller. They are regenerated by Flutter.
